# MVP Screenshots Checklist — AnalystAI

Purpose: a minimal set of screenshots to demonstrate core functionality for the Day 3 checkpoint.

Screens to capture

1. Landing / Hero — show the app header and file-name chip (File: sample_sales.csv)
2. Upload flow — uploader, sample data button, and a successful CSV loaded state
3. Data In Use panel — show filename, rows/columns, and column chips
4. Data Quality / Cleaning — cleaned data preview and cleaning report snippet
5. Chart Studio / AI charts — at least one AI-suggested chart and tweak expander

How to capture

- Open the app at `http://localhost:8500`.
- Use the `Load sample data` button to populate the app.
- Use your OS screenshot tool or Chrome DevTools > Capture full size screenshot.
