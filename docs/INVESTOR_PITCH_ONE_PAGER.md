# One-Page Investor Pitch — AnalystAI

Problem

- Organizations and teams waste days preparing and visualizing CSV data. Non-technical stakeholders cannot quickly extract reliable insights from raw tables.

Solution

- AnalystAI automates detection of issues, smart cleaning, AI-driven chart suggestions, and generates narrative reports plus an interactive Q&A interface created by OpenAI Codex.

Target users

- Small-to-medium businesses, BI teams, product managers, and analysts who need fast exploratory analysis without hiring data engineers.

AI workflow

1. Ingest CSV → automated data profiling (detective)
2. Run cleaning agent → produce cleaned table and cleaning report
3. Chart selector → generate recommended visualizations (plotly)
4. Insight generator → LLM summarises important patterns
5. Storyteller / Q&A → conversational interface for follow-ups

Product vision

- Become the first-click analytics workspace for quick business questions; integrate with cloud storage and dashboards, and offer exportable packs for reporting.

Why it’s valuable

- Reduces analyst preparation time by 70% (target), improves decision speed, and enables non-technical users to ask business questions in plain English.

Metrics to track

- Time-to-insight, user retention, percent of users who publish a report, and reduction in manual cleaning steps.
